DEPLOYMENT & ASSET GUIDE

GitHub Pages + Hostinger Deployment & Asset Replacement Guide

1. GitHub Repository & GitHub Pages Setup

  1. Create a new public repository on GitHub (e.g., parvathareddy-digital).
  2. Upload index.html and your templates/ folder preserving relative paths.
  3. Open Settings → Pages in your GitHub repository.
  4. Under Build and deployment, select Deploy from a branch, choose main and / (root), and click Save.

2. Hostinger Custom Domain & DNS Records

  1. Log in to Hostinger hPanel → Domains → DNS / Nameservers.
  2. Add four A Records for @ pointing to GitHub Pages IPv4 addresses: 185.199.108.153
    185.199.109.153
    185.199.110.153
    185.199.111.153
  3. Add a CNAME Record for www pointing to <your-github-username>.github.io.
  4. In GitHub Settings → Pages → Custom domain, enter your domain, save, and enable Enforce HTTPS once DNS verifies.

3. Required Campaign Assets Checklist

  • The supplied Parvathareddy Digital logo URL is used consistently across the header, modal, and footer.
  • templates/pcsr-leader.png — High-resolution cutout portrait of Parvathareddy Chandrasekhar Reddy (PCSR).
  • templates/mayoral-candidate.jpg — Photograph for the Mayoral Candidate profile card on the home page.
  • templates/ward-1.jpeg through ward-72.jpeg — The 36 ward poster templates.

4. Updating Candidate Names & Coordinates

In WARD_TEMPLATES (or using the visual Calibrator above), each of the 36 wards has its own independent photoSlots and textSlots array. Update candidateNameEn and candidateNameTe with the ward candidate names and click Export Updated templates.js.
