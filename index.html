GitHub Pages + Hostinger Deployment & Asset Replacement Guide

1. GitHub Repository & GitHub Pages Setup

  1. Create a new public repository on GitHub (e.g., pcsr-digital).
  2. Upload index.html and your assets/ folder preserving relative paths.
  3. Open Settings → Pages in your GitHub repository.
  4. Under Build and deployment, select Deploy from a branch, choose main and / (root), and click Save.

2. Hostinger Custom Domain & DNS Records

  1. Log in to Hostinger hPanel → Domains → DNS / Nameservers.
  2. Add four A Records for @ pointing to GitHub Pages IPv4 addresses: 185.199.108.153
    185.199.109.153
    185.199.110.153
    185.199.111.153
  3. Add a CNAME Record for www pointing to <your-github-username>.github.io.
  4. In GitHub Settings → Pages → Custom domain, enter your domain, save, and enable Enforce HTTPS once DNS verifies.

3. Required Campaign Assets Checklist

  • assets/images/logo.png — Official PCSR Digital campaign logo.
  • assets/images/pcsr-leader.png — High-resolution cutout portrait of Parvathareddy Chandrasekhar Reddy (PCSR).
  • assets/images/templates/ward-01.png through ward-72.png — The 72 approved ward-member poster templates (1080×1350 px recommended).
  • SITE_CONFIG.websiteUrl — Set your final custom domain for social share links.

4. Updating Candidate Names & Coordinates

In WARD_TEMPLATES (or using the visual Calibrator above), each of the 72 wards has its own independent photoSlots and textSlots array. Update candidateNameEn and candidateNameTe with the verified ward candidate names and click Export Updated templates.js.
